CineVault — desktop-приложение для организации и просмотра личной коллекции фильмов и сериалов.

Приложение автоматически сканирует локальные папки, определяет медиафайлы, получает информацию о фильмах и сериалах из TMDB и объединяет всё в единую библиотеку с интерфейсом в стиле Netflix и Кинопоиска.

# About

CineVault предназначен для пользователей, которые хранят фильмы и сериалы локально, но хотят работать с ними как с полноценным стриминговым каталогом.

Приложение объединяет локальные файлы и метаданные из TMDB, позволяя:

- хранить фильмы и сериалы в единой библиотеке;
- автоматически определять название, год, сезон и серию;
- получать постеры, описания и другую информацию о медиа;
- запускать локальные видеофайлы непосредственно из приложения;
- продолжать просмотр с сохранённой позиции;
- отслеживать просмотренные фильмы и серии;
- добавлять фильмы и сериалы в список «Хочу посмотреть»;
- ставить собственные оценки;
- оставлять отзывы;
- искать фильмы и сериалы;
- просматривать сезоны и серии внутри сериала;
- просматривать статистику собственной медиатеки.

# Основные возможности

## Библиотека

- сканирование пользовательских папок;
- автоматическое обнаружение видеофайлов;
- определение фильмов и эпизодов сериалов;
- группировка серий по сериалам и сезонам;
- отображение постеров и метаданных;
- сортировка и фильтрация медиатеки.

## Фильмы и сериалы

Для каждого фильма доступны:

- название;
- оригинальное название;
- год;
- описание;
- постер;
- backdrop;
- рейтинг TMDB;
- локальный файл;
- пользовательская оценка;
- пользовательский отзыв;
- статус просмотра.

Для сериалов:

- информация о сериале;
- сезоны;
- список серий;
- информация об отдельных эпизодах;
- статус просмотра серий;
- пользовательская оценка и отзыв.

## Плеер

CineVault позволяет воспроизводить локальные видеофайлы непосредственно из приложения.

Поддерживается:

- запуск локального видео;
- сохранение позиции просмотра;
- продолжение просмотра;
- определение просмотренного контента;
- переключение между эпизодами сериала;
- выбор аудиодорожки;
- выбор субтитров.

В качестве медиадвижка используется **MPV**.

## Продолжить просмотр

Приложение автоматически сохраняет прогресс просмотра и формирует список контента, который пользователь ещё не закончил смотреть.

На главной странице отображаются:

- недавно добавленные материалы;
- продолжение просмотра;
- список «Хочу посмотреть»;
- фильмы;
- сериалы.

## Watchlist

Можно добавлять фильмы и сериалы в список «Хочу посмотреть».

Для элементов watchlist сохраняются:

- название;
- постер;
- описание;
- год;
- тип медиа;
- статус просмотра;
- пользовательская оценка;
- отзыв.

## Рейтинги и отзывы

Пользователь может выставлять собственную оценку контенту по десятибалльной шкале и оставлять текстовый отзыв.

Эти данные используются для персональной статистики и будущего тирлиста.

## Статистика

Отдельная страница статистики содержит информацию о личной медиатеке:

- количество фильмов;
- количество сериалов;
- количество серий;
- количество просмотренного контента;
- количество оставшегося контента;
- количество часов просмотра;
- средняя пользовательская оценка;
- распределение оценок;
- любимые жанры;
- любимые годы;
- активность по месяцам;
- календарь просмотров;
- топ актёров;
- пользовательский тирлист.

# Tech Stack

## Frontend

* **React 19** — построение пользовательского интерфейса
* **TypeScript 5.8** — типизация и разработка frontend-логики
* **Vite 7** — сборка и dev-сервер
* **React Router 8** — маршрутизация между страницами
* **Material UI (MUI) 9** — UI-компоненты и дизайн-система
* **Emotion** — CSS-in-JS для Material UI
* **Framer Motion 12** — анимации и переходы
* **MUI Icons** — набор иконок

## Desktop Application

* **Tauri 2** — desktop runtime и интеграция frontend с нативной частью
* **Rust** — backend и системная логика приложения
* **Tauri Plugins** — доступ к нативным возможностям ОС

## Database

* **SQLite** — локальное хранение данных
* **Tauri SQL Plugin** — взаимодействие с SQLite из приложения

## Media Player

* **MPV** — медиадвижок для воспроизведения локального видео
* **Tauri MPV Plugin** — интеграция MPV с Tauri-приложением

* **TMDB API** — получение информации о фильмах и сериалах
* **Reqwest** — HTTP-клиент на Rust для запросов к API
* **Serde / Serde JSON** — сериализация и десериализация данных

## File System

* **Tauri File System / Asset Protocol** — работа с локальными файлами и медиаконтентом
* **Walkdir** — рекурсивное сканирование директорий
* **Regex** — анализ и распознавание названий файлов
* **Urlencoding** — кодирование параметров URL

## Tauri Plugins

* **Tauri Dialog Plugin** — системные диалоги выбора файлов и папок
* **Tauri Opener Plugin** — открытие внешних ссылок и ресурсов
* **Tauri SQL Plugin** — работа с локальной SQLite-базой
* **Tauri MPV Plugin** — интеграция медиаплеера

## TMDB Integration

CineVault использует TMDB для автоматического обогащения локальной библиотеки метаданными.

После обнаружения локального файла приложение анализирует его название и определяет возможный фильм или сериал.

Для сериалов дополнительно определяется:
- сезон;
- номер эпизода.

После определения контента приложение получает соответствующие данные из TMDB.
Полученные метаданные сохраняются локально и используются интерфейсом приложения без необходимости повторно запрашивать API при каждом открытии страницы.
